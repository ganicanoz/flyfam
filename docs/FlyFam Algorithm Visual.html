Uçuş Fazları
PASSIVE_FUTURE
now < STD − 3h  ·  API çağrısı yok  ·  Roster verisi korunur
SEMI_ACTIVE
STD − 3h → STD − 20dk  ·  1 saatte bir  ·  Airlabs → ADB fallback
ACTIVE
STD − 20dk → iniş + 2dk  ·  Sub-window'a göre sıklık  ·  FR24 + Airlabs
PASSIVE_PAST
Uçuş tamamlandı  ·  API çağrısı yok  ·  status = LANDED (final)
⚠️ Force-Close Kuralı
Eğer now > STA + 3h ve uçuş hâlâ ACTIVE ise:
• actual_arr / datetime_landed / last_seen varsa → LANDED
• Hiçbiri yoksa → UNKNOWN + review_flag = true

Karar Motoru — FR24 Bulundu
flight_ended = false
• first_seen = null → SCHEDULED
• first_seen var, takeoff yok, now < STD+30dk → TAXI_OUT
• first_seen var, takeoff yok, STD+30dk → STD+90dk → DELAYED
• first_seen var, takeoff yok, now ≥ STD+90dk → UNKNOWN
• takeoff var, landed yok → EN_ROUTE
• landed var → LANDED_CANDIDATE
flight_ended = true
• datetime_landed al → LANDED  ·  faz = PASSIVE_PAST
Karar Motoru — FR24 Bulunamadı (Airlabs Fallback)
• Airlabs = en-route → EN_ROUTE
• Airlabs = landed → LANDED_CANDIDATE (teyit bekle)
• Airlabs = scheduled + now > STD+30dk → DELAYED
• Airlabs = scheduled + now ≤ STD+30dk → zamanları güncelle, status değiştirme
• Airlabs da yok → önceki status koru, log at
LANDED_CANDIDATE → Onay Şartları
Güçlü (hemen LANDED): datetime_landed var veya flight_ended = true
Orta (LANDED, low confidence): last_seen var + now − last_seen ≥ 20dk
Zayıf (bekle, bildirim gönderme): Sadece Airlabs landed
Roster Import Kuralları
📄 Roster Lock: source = ROSTER_IMPORT ve faz = PASSIVE_FUTURE ise
→ Hiçbir API çağrısı yapılmaz
→ scheduled_dep / scheduled_arr değiştirilmez
→ is_roster_verified = false olarak kalır
🔓 Roster Unlock: Faz SEMI_ACTIVE olduğunda
→ Airlabs ile ilk external validation yapılır
→ Başarılıysa is_roster_verified = true
→ Schedule güncellenir (strict date match zorunlu)
⚠️ Timezone Uyarısı: Roster PDF'leri local / UTC / base time karışık gelebilir

→ departure_date_local_origin explicit olarak yaz
→ Faz geçişlerini unverified timezone'a göre tetikleme

3Sadece first_seen ile sonsuza kadar TAXI_OUT'ta kalma — timeout ekle (STD+30dk → DELAYED)
