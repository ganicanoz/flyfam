FlyFam uygulama ekran haritası

Ana navigasyon kaynağı: mobile/App.tsx (React Navigation). Crew ve aile aynı ana sekmeleri paylaşır; ek stack ekranları Program / Aile / Profil üzerinden açılır.

~22 farklı ekran (App stack) 4 ana sekme (+ peer sekmeleri) Auth → kurulum → Main Görseller: marketing-v3 (varsa)
Kaç ekran? Çalıştığımız ana uygulama yolunda kabaca 22 ekran var: 5 auth, 3 kapı (şifre / profil tamamlama / onay), 4+ ana sekme (Program, peer Program’lar, Aile, Profil), ~10 stack (uçuş ekle/düzenle, planlar, bağlan, admin…). Expo Router altındaki app/(app)/… dosyaları paralel/eski yüzey; canlı native akış App.tsx.
