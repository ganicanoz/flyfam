Havalimanı uçuş listesi: göreceli vs zaman aralıklı

FlyFam’da ana senaryo belirli bir roster günü + uçuş numarası olduğu için çoğu zaman uçuş numarası veya tarihli aralık daha uygundur. Bu tablo, iki AeroDataBox tarzı yaklaşımı yan yana özetler; örnekler SAW için illüstratiftir (canlı API çağrısı değildir).

Özellik Göreceli
GetAirportFlightsRelative 		Aralıklı
GetAirportFlights
Sorgu fikri “Şu andan itibaren önümüzdeki 12 saat” — sabit takvim günü yok. “2026-04-02 18:00 ile 2026-04-03 06:00 arası” — kesin ISO aralığı.
FlyFam UX Canlı FIDS / “şu an SAW’da ne var?” ekranı için uygun. Roster’daki dün/yarın bacakları tek başına çözmeyebilir. Roster flight_date + STA/STD etrafında pencere açıp o günün varış/kalkışı bulmak için uygun.
API maliyeti / hacim Periyot başına tek “şimdi + N saat”; arka planda sık yenilerseniz çağrı sayısı artar. Uçuş başına dar pencere (ör. ±3 saat STA) ile daha az gereksiz kayıt; parametre doğru seçilirse verimli.
SAW örneği — Kalkış (Dep)
Kavramsal parametreler
airport: SAW
direction: Departure
from: now (UTC veya local API kuralına göre)
to:   now + 12h
18:00 → ertesi gün 06:00 (gece yarısını keser)
airport: SAW
direction: Departure
from: 2026-04-02T18:00:00+03:00
to:   2026-04-03T06:00:00+03:00

Not: Uçuşlar UTC’de saklanıyorsa aralığı UTC’ye çevirip aynı mantığı uygulayın.
SAW örneği — Varış (Arr)
Aynı göreceli pencere, yön değişir
airport: SAW
direction: Arrival
from: now
to:   now + 12h
Aynı saat aralığı, varış tahtası
airport: SAW
direction: Arrival
from: 2026-04-02T18:00:00+03:00
to:   2026-04-03T06:00:00+03:00
Timetable satırı eşleme Listeyi filtreleyip number / flight_iata ile eşleştirme; “yarının” uçuşu listede yoksa kaçırılır. Roster günü + beklenen varış/kalkış saatine göre dar pencere → PC2009 gibi vakalarda daha kontrollü arama.

Özet tavsiye (FlyFam)

Roster odaklı ürün: Birincil yol uçuş numarası + tarih. Number lookup boş veya Departed’da takılı kalıyorsa fallback olarak hedef meydan (ör. SAW) + Arrival + STA çevresinde dar ISO aralığı (GetAirportFlights tarzı) daha tutarlıdır. Tam ekran FIDS istenirse göreceli endpoint ek maliyetle anlık tahta sunar.
