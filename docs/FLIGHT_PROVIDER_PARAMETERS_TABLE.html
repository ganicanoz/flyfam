FlyFam — Sağlayıcı parametre eşlemesi (güncel)

Bu tablo crew PDF roster import (bizim için birinci kaynak / “iç API”) ile harici sağlayıcıları birlikte gösterir. Entegrasyon: mobile/lib/flightApi.ts, check-flight-status-and-notify, rosterPollEdge, flightByNumberEdge (FlightAPI yedek plan); AirLabs düz /flight modeli. FlightAPI dokümantasyonu.

PDF import: Yalnızca satır 1–5’teki plan verileri gelir (uçuş no, meydanlar, STD/STA); DB’de flights tablosuna yazılır — tahmin/gerçek zaman veya transponder alanları yok.
FR24: Yalnızca GET …/api/flight-summary/light (bacak özeti). Ayrı “full flight summary” endpoint’i bu repoda yok.
FlightAPI: Edge’de GET https://api.flightapi.io/airline/{api_key}?num=&name=&date=YYYYMMDD (flight tracking). …/schedule/ (havalimanı programı) henüz zincire bağlı değil.
Faz: Her uçuşun api_refresh_phase değeri aşağıdaki faz tablosunda özetlenir; hesap: compute_flight_api_phase_state + tetikleyici (20260330120000_pdf_spec_api_refresh_phase.sql). ETD = coalesce(estimated_departure, scheduled_departure + delay_dep_min).

Kısa referans

PDF import (crew)

Roster PDF’ten çıkarılan uçuş satırı; uygulama bunu harici API gibi kullanır: plan STD/STA ve rota kaynak gerçeği olarak flights.scheduled_* / flight_number / meydan kolonlarına yazılır. Satır 6–14 bu kaynakta yok (ETD/ETA/ATD/ATA ve canlı sinyaller sonradan cron veya mobil arama ile dolar).

AirLabs (iç içe departure değil)

Kodda kullanılan örnekler: dep_time_utc, arr_time_utc, dep_actual_utc, arr_actual_utc, dep_estimated_utc, arr_estimated_utc, dep_iata, arr_iata, status, percent, dep_delayed, arr_delayed.

AeroDataBox

Zamanlar: departure / arrival (veya departures[0].departure) altında scheduledTimeUtc, predictedTimeUtc, estimatedTimeUtc vb. (aeroCoerceTimeString ile).

FR24 Summary Light

Bacak seçimi, plan/tahmin/iniş zamanları, flight_ended, first_seen / last_seen / datetime_takeoff / datetime_landed. Not: last_seen tek başına iniş kanıtı değildir.

FlightAPI (Flight Tracking)

JSON dizi; departure / arrival öğeleri. Edge: departureDateTime, arrivalDateTime, estimatedTime, airportCode. İstek ücreti: docs.flightapi.io.
