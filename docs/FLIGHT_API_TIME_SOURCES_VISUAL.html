Sağlayıcı Endpoint (özet) Scheduled Estimated Actual / operasyonel
FR24 fr24api.../flight-summary/light scheduled_departure(_utc), scheduled_arrival(_utc) estimated_*, eta → DB’de fr24_progress_* İz datetime_takeoff, datetime_landed, first_seen, last_seen
AirLabs airlabs.co/api/v9/flight dep_time, arr_time, dep_scheduled… dep_estimated, arr_estimated (cron’da öncelikli zincir) dep_actual, arr_actual (mobilde doğrudan actual_*)

AeroDataBox aerodatabox.../flights/number/… scheduledTime* predictedTime*, estimatedTime* Poll satırında actual boş; birleşik sched ?? est
AeroAPI aeroapi.../flights/{ident} scheduled_out/in estimated_out/in actual_out/in
Aviationstack api.aviationstack.com/v1/flights departure.scheduled, arrival.scheduled *.estimated *.actual
